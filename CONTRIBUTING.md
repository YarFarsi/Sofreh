# Contributing

This project targets air-gapped on-premise deployments.

- Do not add runtime CDN, cloud auth, or hosted font dependencies.
- Keep Persian RTL as the default UI.
- Prefer server-side authorization and tests around cutoff, capacity, and serving.
- Conventional commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`.
- Do not commit `.env`, secrets, or real employee data.
