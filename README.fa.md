# سامانه رزرو غذا (درون‌سازمانی و آفلاین)

سامانه وب فارسی و راست‌چین برای رزرو غذای کارکنان. اجرا به‌صورت کامل روی شبکه داخلی سازمان، **بدون نیاز به اینترنت در زمان بهره‌برداری**.

## اطلاعات ورود نمونه (فقط محیط آزمایش)

در محیط عملیاتی از این رمزها استفاده نکنید.

| نقش | ایمیل | رمز |
| --- | --- | --- |
| مدیر | `admin@example.local` | `ChangeMe-Admin-0!` |
| کاربر | `user@example.local` | `ChangeMe-User-0!` |
| کاربر در انتظار تأیید | `pending@example.local` | `ChangeMe-Pending-0!` |

## نصب و راه‌اندازی (توسعه)

```bash
cp .env.example .env
docker compose up -d db
npx prisma migrate dev
npx prisma db seed
npm run dev
```

نشانی: `http://localhost:3000`

## استقرار آفلاین

۱. روی ماشین دارای اینترنت: `bash scripts/build-offline-bundle.sh 0.1.0`  
۲. انتقال بسته با رسانه تأییدشده  
۳. `docker load -i docker-images/images.tar.gz`  
۴. تنظیم `.env` (رمز پایگاه، `SESSION_SECRET`، `APP_URL`)  
۵. `docker compose up -d` (مهاجرت پایگاه در ورود به کانتینر اجرا می‌شود)  
۶. در صورت `SEED_DEMO=true` مدیر نمونه ساخته می‌شود؛ در تولید `SEED_DEMO=false`  
۷. بررسی سلامت: `curl http://food.company.local:3000/api/health`  
۸. پشتیبان‌گیری: `bash scripts/backup.sh`  
۹. بازیابی فقط پس از آزمایش `scripts/restore.sh` روی محیط آزمایشی معتبر است

## تنظیمات

از منوی مدیریت → تنظیمات: منطقه زمانی (پیش‌فرض `Asia/Tehran`)، روز شروع هفته، مهلت رزرو، مهلت لغو، فهرست انتظار، زمان وعده‌ها.

## ایجاد مدیر

با سید دمو یا با ثبت‌نام + تأیید در «کاربران». رمز تولید باید قوی باشد.

## مدیریت غذا و منوی هفتگی

غذا را تعریف کنید (حذف فیزیکی غذاهای دارای تاریخچه انجام نمی‌شود؛ غیرفعال می‌شوند). سپس برای هر روز و وعده، آیتم منو بسازید. قیمت روی آیتم منو و رزرو قفل تاریخی می‌شود.

## رزرو و تحویل

کاربر منوی شمسی هفته را می‌بیند و رزرو می‌کند. بلیت QR در «رزروهای من» است. اپراتور در «تحویل غذا» اسکن می‌کند و دکمه **تحویل غذا** را می‌زند. اسکن دوم پیام «این غذا قبلاً تحویل شده است.» را می‌دهد.

## گزارش‌ها و پشتیبان‌گیری

گزارش هزینه هفتگی، تعداد غذا و تحویل‌نشده با خروجی `.xlsx` آفلاین. پشتیبان پایگاه و فایل‌های آپلود در `scripts/backup.sh`.
